## 2026-11-25 — Сессия 1
- Изучены спецификации (10 md) и 14 макетов из архива `Auden_Alpha_Development.zip`. Оригиналы спецификаций скопированы в `docs/spec/`, 7 ключевых макетов — сжатые в `docs/design/`.
- Составлен план (`docs/PLAN.md`) и журнал решений (`docs/DECISIONS.md`); выявлены решения, требующие подтверждения владельца (хостинг, Supabase, ключ OpenRouter, юридические вопросы).
- Scaffold: Next.js 16.4, React 19.2, TypeScript, Vitest 5, ESLint 9, Playwright 1.63 (совпадает с предустановленным браузером).
- **Core Engine** (`src/core`): провайдеры mock / openai‑compatible / openrouter (только free), engine с fallback‑цепочкой, retry с backoff только до первого токена, timeout первого токена и общий, отмена; сборщик контекста с бюджетом токенов; квоты по данным БД. Проверено: 26 unit‑тестов.
- **Данные**: интерфейс `UserStore`, local JSON‑адаптер, Supabase‑адаптер; миграция с RLS, триггерами владения, append‑only `usage_events`, `global_usage_since`, `delete_my_account`. Проверено: `npm run test:rls` на временном Postgres 16 (изоляция, подделка владельца, каскады, удаление аккаунта, анонимный доступ).
  - Проблема: `useradd` для запуска Postgres не от root отклонён политикой окружения → скрипт использует существующего пользователя `nobody`.
  - Баг найден тестом: PL/pgSQL не делает short‑circuit в `AND` с `NEW.поле` другой таблицы → вложенный IF.
- **API** (`src/server/api.ts`): web‑standard обработчики, один catch‑all route Next. Проверено: 18 интеграционных тестов (изоляция аккаунтов, квоты, память с согласием, область памяти проекта, экспорт/удаление, CSRF).
- **UI**: вход, чат, история, проекты, память, настройки; RU/EN; светлая/тёмная/системная тема; desktop/mobile. Проверено: 14 e2e Playwright, скриншоты 360/768/1440.
- **Безопасность**: найдено при ревью — через anon key пользователь мог бы вставлять `usage_events` напрямую и исчерпать глобальный лимит для всех или сработать бюджетный потолок. Исправлено: вклад пользователя в глобальный счётчик ограничен его дневной квотой, RLS принимает только `cost = 0`. Покрыто RLS‑тестом.
