# Auden — спецификация Alpha 0.1
Цель: доступный русско-английский ИИ-помощник для проектов, с переходом к собственным моделям. MVP: адаптивная PWA, регистрация, чат со streaming, история, проекты, настройки тем, выбор режима и управляемая память. Файлы — текст/PDF с ограничениями и проверкой. Голос, изображения, агенты, платежи — после MVP. Не имитировать работающие функции.
Приёмка: два тестовых аккаунта не видят данные друг друга; чат работает с mock и реальным провайдером; история переживает перезагрузку; лимиты действуют на сервере; ошибки понятны; удаление чата и памяти проверено; интерфейс адаптивен на 360–1440 px. RU/EN, доступность клавиатуры, контраст.
