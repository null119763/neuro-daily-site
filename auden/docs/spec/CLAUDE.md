# Инструкции Claude Code
Прочитай все markdown и приоритетные референсы. Начни с плана, дерева репозитория и mock PWA; затем реализуй этапы ROADMAP. После каждого этапа запускай тесты и обновляй STATUS.md (решения, известные баги, следующий шаг). Не покупать услуги, не публиковать, не добавлять платные модели, не отправлять реальные пользовательские данные без согласия. Запрашивать подтверждение перед затратами и необратимыми действиями. Не считать макеты работающими функциями. При приближении к лимиту контекста записать состояние и инструкции продолжения; новую сессию запускает пользователь или настроенный им оркестратор. Первый шаг: scaffold, mock chat, адаптивная тема, README с командами запуска и тестов.
