# Безопасность
Секреты в environment, .env.example без ключей. Серверные квоты per-user и глобальный денежный потолок, ограничение размера входа и файлов, rate limit, защита от prompt injection: документы недоверенные, никакого выполнения команд модели. TLS, RLS, приватное хранилище, минимальные логи, экспорт и удаление данных, политика приватности и сроки хранения. Проверить GDPR и возрастные ограничения, договоры поставщиков и участие законного представителя при необходимости. Обучение только на отдельно разрешённых данных, без приватных диалогов по умолчанию.
