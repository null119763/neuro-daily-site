# Память
Выключаемая персональная память, просмотр, исправление и удаление записей. Сохранять только полезные утверждения с provenance и датой; пользователь подтверждает предложенные записи. Поиск сначала SQL, затем pgvector при необходимости. Изоляция пользователей и проектов. Не путать RAG с обучением весов. История и память не становятся обучающим датасетом автоматически.
