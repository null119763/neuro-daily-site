# Auden Labs
Цель — собственная модель, не просто оболочка. Начать с лицензированной открытой модели 1–8B. Проверить лицензию на коммерческое использование и производные веса. Создать версионированный датасет из разрешённых источников; dedup, PII filtering, provenance, train/validation/test без утечки. Базовые оценки RU/EN, код, математика, факты, безопасность, стоимость и задержка. LoRA/QLoRA с PEFT/Transformers на арендуемой GPU; фиксировать seed, параметры, версии данных, расходы. SFT затем DPO при наличии качественных предпочтений. Не использовать ответы платных API для обучения без разрешения условий. Сравнить новую модель с неизменённой базой на закрытых тестах и человеческих оценках. Model registry, model card, canary, rollback. Не утверждать превосходство без воспроизводимых результатов. Обучение с нуля — отдельная исследовательская программа после инвестиций, расчёта токенов/FLOP, найма ML команды и создания кластера.
