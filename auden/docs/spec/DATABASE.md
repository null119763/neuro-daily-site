# Данные
Таблицы profiles(id), projects(id,user_id,title), conversations(id,user_id,project_id,title), messages(id,conversation_id,role,content,provider,model,created_at), memories(id,user_id,content,source,consent,created_at), attachments(id,user_id,conversation_id,path,mime,size), usage_events(id,user_id,model,input_tokens,output_tokens,cost,created_at), training_consents(id,user_id,version,granted_at,revoked_at). UUID, FK, индексы владельца и даты, RLS по auth.uid(), каскады с проверкой политики хранения. Storage private. SQL migrations и тесты RLS обязательны. Не хранить секреты в профилях.
