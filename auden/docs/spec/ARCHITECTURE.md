# Архитектура
Начать с Next.js TypeScript PWA и серверных routes, Supabase Auth/Postgres/Storage. Не вводить отдельный FastAPI или Flutter до необходимости. Разделить UI, domain, providers, persistence. API: POST /api/chat (SSE), CRUD /api/conversations, /api/projects, /api/memory; GET /api/usage. Проверять сессию и владельца каждого объекта. Провайдеры взаимозаменяемы через интерфейс stream(request), capabilities(), estimateCost(). Mock для разработки, OpenRouter для теста, позднее vLLM для собственных весов. Фоновые задачи позже через очередь и worker. Запуск локально, затем бесплатный совместимый хостинг после проверки условий и лимитов SSE. CI: lint, typecheck, unit, integration, e2e.
