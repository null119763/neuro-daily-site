# Архитектурные решения (ADR‑журнал)

## Принятые

**D1. Расположение кода.** Репозиторий `neuro-daily-site` уже содержит статический сайт NEURO DAILY (index.html, файл верификации TikTok). Auden размещён в `auden/` как самостоятельное приложение, чтобы не ломать сайт. Вынос в отдельный репозиторий — по решению владельца (см. P4).

**D2. Стек.** Next.js 16 (App Router) + TypeScript + React 19, обычный CSS с CSS‑переменными (без Tailwind — меньше зависимостей, токены дизайн‑системы напрямую). Тесты: Vitest (unit/integration), Playwright (e2e).

**D3. Два адаптера данных.** `AUDEN_BACKEND=local` (по умолчанию) — JSON‑файл + собственная аутентификация, для разработки/тестов. `AUDEN_BACKEND=supabase` — продакшен с RLS. Оба реализуют один интерфейс `Store`, интеграционные тесты гоняются против local, RLS проверяется SQL‑тестами на настоящем Postgres.

**D4. Квоты на основе БД.** Rate limit и дневные квоты считаются по `usage_events`, а не в памяти процесса — работает на serverless‑хостинге. Глобальный дневной потолок — через `SECURITY DEFINER` функцию (RLS не даёт пользователю видеть чужие записи). Пользователь не может удалять/менять свои `usage_events` (иначе сбросил бы квоту).

**D5. Только бесплатные модели OpenRouter.** Проверка `:free`/нулевой цены в коде; платный fallback отсутствует. Режимы Air/Core/Prime задаются списками моделей в env; без env — автоподбор из каталога бесплатных моделей OpenRouter.

**D6. Логотип и иконка (решение владельца, 2026-11-25).** Логотип — восьмилучевая «искра» с присланной владельцем иконки: длинные вертикальные/горизонтальные лучи и короче, мягче диагональные (`src/ui/components/Logo.tsx`, `public/icon.svg`). Иконка приложения (PWA, apple‑touch) — присланное изображение (`docs/design/app-icon.jpg` → `public/icon-*.png`). Уникальность товарного знака не проверена (P6); радиальная «искра» как класс знаков встречается у других ИИ‑продуктов — стоит учесть при регистрации.

**D10. Типографика.** Self‑hosted шрифты из npm (`@fontsource-variable`, лицензия OFL, без запросов к Google): Source Serif 4 — заголовки, логотип и текст ответов ИИ (книжный кегль 17px, интерлиньяж 1.7); Inter — интерфейс. Оба с кириллицей.

**D7. Память.** `memories.consent=false` — предложение, ожидающее подтверждения; `true` — подтверждённая запись. В контекст модели попадают только подтверждённые записи и только если память включена в профиле. Предложения создаются явной командой («запомни …» / «remember …») или кнопкой «В память»; автоматическое извлечение LLM‑ом отложено (тратит запросы квоты).

**D8. API как web‑standard обработчики.** `handleApi(Request) → Response` в `src/server/api.ts`, Next подключает через один catch‑all route. API тестируется без Next и переносим на другой рантайм (Workers, Node).

**D9. Глобальный счётчик устойчив к злоупотреблению.** Вклад одного пользователя ограничен его дневной квотой; через JWT пользователя можно записать только usage с `cost = 0`. При включении платных моделей учёт переводится на service role.

**D11. Вложения хранят только текст.** Исходный файл не сохраняется: меньше персональных данных, не нужен Storage (бесплатно), проще удаление. Минус: оригинал нельзя скачать обратно, сканы без текстового слоя не читаются (нужен OCR — позже). Тип файла определяется по содержимому; документы — недоверенные данные в контексте модели.

## Ожидают подтверждения владельца

**P1. Хостинг.** Vercel Hobby бесплатен, но по условиям запрещает коммерческое использование. Альтернативы с бесплатным тарифом: Netlify Free, Cloudflare Workers (через OpenNext), Render Free (засыпает). Нужен выбор и проверка лимитов SSE. До решения — только локальный запуск.

**P2. Supabase.** Нужен бесплатный проект Supabase (создаёт владелец; free‑проект засыпает после недели неактивности, 500 МБ БД). Ключи кладутся в env хостинга, не в репозиторий.

**P3. OpenRouter.** Нужен API‑ключ владельца. Ограничения бесплатных моделей (по данным 2025 г., перепроверить перед запуском): ~20 запросов/мин и 50 запросов/день на аккаунт без купленных кредитов (1000/день после разовой покупки ≥ $10 — **платное действие, только с разрешения**). Важно: у части бесплатных моделей провайдеры могут логировать/использовать запросы — это нужно отразить в политике конфиденциальности и согласии пользователей до закрытой альфы.

**P4. Репозиторий.** Оставить Auden в `neuro-daily-site/auden` или перенести в отдельный репозиторий `auden` (рекомендуется для коммерческого продукта: отдельные права, CI, лицензия).

**P5. Юридическое.** Политика конфиденциальности, условия использования, GDPR/152‑ФЗ, возрастные ограничения — до приёма внешних пользователей. Лицензия кода (сейчас не задана = все права защищены).

**P6. Название и логотип.** Проверка товарного знака «Auden».
