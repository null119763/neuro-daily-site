# Инструкции для Claude Code (Auden)

- Перед работой прочитай `PROJECT_STATE.md`, `TASKS.md`, `docs/DECISIONS.md`; требования — `docs/spec/`.
- Не подключать платные услуги, не публиковать и не деплоить без разрешения владельца.
- Секреты только в env (`.env.local`, не коммитится); `.env.example` — без значений.
- Не выдавать макеты за работающие функции: незавершённое помечать в UI как «Скоро».
- Каждый модуль: тесты (`npm run check`), запись в `DEVELOPMENT_LOG.md`, отметка в `TASKS.md`, небольшой коммит.
- При приближении к лимиту контекста обнови `PROJECT_STATE.md` (что сделано, что в процессе, следующий шаг).
