## Известные ограничения / техдолг
- [x] Rate limit входа (по email и IP) и регистраций (по IP) — в памяти инстанса; для нескольких инстансов нужен общий счётчик
- [ ] Проверка квоты не атомарна: при параллельных запросах возможен перерасход на 1–2 запроса
- [ ] Ретраи engine не учитываются в глобальном счётчике отдельно (OpenRouter считает каждую попытку) — держать `AUDEN_GLOBAL_DAILY_REQUESTS` с запасом
- [x] «Повторить» перегенерирует ответ (`regenerate: true`), без дубля сообщения; старый ответ удаляется только после успешного нового
- [ ] Платный учёт (cost > 0) потребует записи usage через service role (см. миграцию)
- [ ] Local‑бэкенд не годится для serverless/многих инстансов — только dev/тест/демо
